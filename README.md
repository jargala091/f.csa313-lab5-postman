## Ажиллуулах

Терминалд эхлээд серверээ асаана:

```sh
node server.js
```

Өөр терминалд collection-ийг ажиллуулна:

```sh
newman run lab05-collection.json
```

Энэ collection дахь хүсэлт бүр өөрийн оюутан, хичээлийн өгөгдлийг `PUT` хүсэлтээр бэлддэг. Иймээс өмнөх хүсэлтийн өгөгдөл болон `registrationID`-ийн тодорхой утгаас хамаарахгүй.

## Сонголт ба төлөөлөх утгууд

| Сонголт | Төлөөлөх утгууд |
|---|---|
| Оюутны төлөв | Идэвхтэй (`active`), идэвхгүй (`inactive`), байхгүй ID |
| Оюутны үзсэн хичээл | Урьдач нөхцөлийг хангасан, огт хангаагүй, заримыг хангасан, хоосон жагсаалт |
| Хичээлийн ID | Байгаа, байхгүй |
| Урьдач нөхцөл | Байхгүй, нэг эсвэл хэд хэдэн хичээл; бүгд, зарим нь эсвэл аль нь ч үзэгдээгүй |
| Хүсэлтийн талбар | `studentID` ба `courseID` хоёулаа байгаа, нэг нь дутуу |

## Тестийн спецификаци

| № | Тохиолдол | Хүлээгдэх статус | Хүлээгдэх `result` |
|---:|---|---:|---|
| 1 | Идэвхтэй оюутан бүх урьдач хичээлийг үзсэн | 201 | `OK` |
| 2 | Оюутны бичлэг байхгүй | 200 | `ERROR_NO_STUDENT` |
| 3 | Оюутан идэвхгүй | 200 | `ERROR_INACTIVE_STUDENT` |
| 4 | Хичээлийн бичлэг байхгүй | 200 | `ERROR_NO_COURSE` |
| 5 | Урьдач хичээл огт үзээгүй | 200 | `ERROR_PREREQUISITES` |
| 6 | Хоёр урьдачийн нэгийг үзсэн | 200 | `ERROR_PREREQUISITES` |
| 7 | Урьдач нөхцөлгүй хичээлд хоосон үзсэн хичээлтэй бүртгүүлэх | 201 | `OK` |
| 8 | `studentID` талбар дутуу | 400 | `ERROR_BAD_REQUEST` |
| 9 | `courseID` талбар дутуу | 400 | `ERROR_BAD_REQUEST` |

Тохиолдол бүрт хоёр assertion ажиллана: HTTP статус болон хариуны `result`. PASS тайланд 9 тестийн script, 25 request, 18 assertion ажиллаж, 0 assertion унасан.

## Newman үр дүн

PASS ажиллуулалтад Node.js `v24.10.0`, Newman `6.2.3` ашиглав. Сервер ажиллаж байх үед дараах тайланг авсан:

```sh
mkdir -p results
newman run lab05-collection.json 2>&1 | tee results/newman-pass.txt
```

| Файл | Ажилласан байдал | Assertion | Exit code |
|---|---|---:|---:|
| `results/newman-pass.txt` | 25 request, 18 assertion, 0 унасан | 0 failed | 0 |
| `results/newman-fail.txt` | Алдаатай oracle дээр 1 assertion унасан | 1 failed | 1 |
| `results/newman-down.txt` | Сервер зогсоосны дараа холболт бүтэлгүйтсэн | Холболт тогтоогүй | 1 |

Сервер зогссон үед `ECONNREFUSED` нь хүсэлт серверт хүрээгүй интерфейсийн холболтын алдаа юм. Сервер хариу өгсөн ч буруу статус эсвэл утга ирэхэд assertion унана; энэ нь холболтын алдаа биш.

## Дүгнэлт

Тестийн дизайны таван алхмаас төлөөлөх утгуудыг тодорхойлох хэсэгт оюутны төлөв, хичээлийн оршин байх эсэх, урьдач нөхцөлийг зэрэг тооцсон. Оюутан байхгүй тохиолдолд идэвхтэй эсэхийг шалгах боломжгүй тул энэ хослол утгагүй. Идэвхгүй оюутан дээр урьдач нөхцөлийг хангаагүй бол API эхэлж идэвхгүй төлөвийн алдааг буцааж байгааг туршилтын эрэмбээр шалгаж болно. Бүртгэл амжилттай болсон үед `registrationID` серверийн өмнөх төлөвөөс хамаарах тул яг утгыг шалгаагүй. Харин зөвхөн статус болон `result`-ийг тус бүрийн oracle болгосон. Newman-ийн PASS ажиллуулалтад 9 тохиолдлын 18 assertion бүгд амжилттай болсон. Алдаатай collection нь зөв хариу 201 байхад 200 хүлээсэн oracle-ийг илрүүлж нэг assertion унагасан. Серверийг зогсоосон үед тестүүд `ECONNREFUSED` авсан бөгөөд энэ нь серверийн бизнес дүрмийн алдаа биш. Эдгээр туршилтаар API-ийн зааварт нийцээгүй согог илрээгүй.
